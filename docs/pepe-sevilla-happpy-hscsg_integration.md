## 8. EXPERIMENTO PROPUESTO (NO ALIANZA DEFINITIVA)

### Protocolo de Experimentación

1. **Tomar una parte pequeña** del universo Pepe (ej. Superpoderes + Domina/Delega/Desecha)
2. **Convertir en Quest interactiva** (HSCSG loopEngine + Autómata + CoachFAB)
3. **Grupo piloto** (20-50 personas reales)
4. **Observar métricas:**
   - ¿Qué utilizan? ¿Qué ignoran?
   - ¿Qué les emociona? ¿Qué recuerdan?
   - ¿Qué quieren repetir? ¿Qué empiezan a construir?
5. **Decidir juntos:**
   - Si funciona → **profundizamos**
   - Si no funciona → **aprendemos**

**Inversión:** Tiempo + curiosidad (no capital inicial)
