```
1. DIAGNÓSTICO (15 min)
   → Ejecuta: node scripts/orchestrator-next-steps.js status
   → Identifica tu workstream: P0_SPECS / MIGRATION / COACH / ROLES / DEPLOY / GAIA_INTEGRATION

2. ASIMILACIÓN DIRIGIDA (2-4 hrs)
   → Sigue BRIEF_ONBOARDING_CONSTRUCTOR.md Fases 1-4
   → Tu repo fuente = tu especialidad (paper, código, metodología)
   → Output: *_backup.md + *_integration.md + spec en lib/

3. CONTRIBUCIÓN ESPECIALIZADA
   → Crea/extiende módulo en src/core/lib/tu-especialidad.ts
   → Añade tests verificables (sensor-verifiable per CAC)
   → Integra en store + pantalla + vasos comunicantes

4. FEDERACIÓN (continuo)
   → Tu módulo expone API via vaso correspondiente
   → governance:sync (CDS), trust:bridge (ERC-8004), infra:connect (neko)
   → eco:sync (CAC/PGS bidireccional con Gaia Score)
```
