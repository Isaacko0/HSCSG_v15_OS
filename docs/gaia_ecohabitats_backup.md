**Qué es:** Gaia Union se modela como un **organismo vivo regenerativo** con niveles de organización biológicos y "sistemas vitales" análogos a los sistemas fisiológicos.

## Niveles de Organización (Ontología Jerárquica)
- **Personas → Células**: unidad fundamental; aportan capacidades, conocimiento, experiencias, creatividad, energía, propósito únicos.
- **Equipos/Comunidades/Redes → Tejidos**: capacidades colectivas imposibles para individuos aislados; se organizan alrededor de función/propósito/territorio compartido.
- **Proyectos/Orgs/Instituciones → Órganos**: estructuras especializadas (empresas regenerativas, cooperativas, escuelas, fundaciones, centros comunitarios, proyectos de impacto). Cada órgano contribuye al bienestar del conjunto desde su especialización.
- **Sistemas Gaia → Sistemas Vitales**: coordinan múltiples órganos y tejidos para funciones complejas del ecosistema.
- **Gaia Union (DHE) → Organismo Vivo Completo**: totalidad de personas, comunidades, organizaciones, territorios, conocimientos, recursos, infraestructuras y sistemas.

## Arquitectura Fundamental (ADN + Código Genético + Epigenética)
- **Gaia Constitution = ADN del ecosistema**: contiene principios, acuerdos, derechos, responsabilidades y patrones fundamentales que orientan el desarrollo del ecosistema. Así como el ADN guía el desarrollo de un organismo, la Constitución Gaia guía la evolución de Gaia Union.
- **Valores/Principios = Código Genético**: patrones fundamentales que orientan cultura y comportamiento: Regeneración, Cooperación, Transparencia, Diversidad, Soberanía, Interdependencia, Amor, Servicio.
- **Gobernanza = Sistema Epigenético**: permite adaptar la expresión del ecosistema a distintos contextos y necesidades sin alterar su esencia. Coordina toma de decisiones, asignación de responsabilidades y evolución colectiva.
