Quiere una **OS de comunidad federada abierta** donde pueda crear grupos por región/tema, eventos, y gobernar por contribución — sin plataforma cerrada (Verint) ni sin internet (cuando está offline, el nodo local mantiene su comunidad).

### 🤖 LLM (qué asimilar)
**CONSERVAR (isomorfo a civilizaciones/celulas + Hylo fork):**
- Grupos por región + tema → `células` + `dominios` (federación Dunbar).
- Gobernanza por PR/contribución → `propuestas` vecinales + `tasks` del nodo.
- Code of Conduct + Committee → capa humana (Kleros + Wisdom Councils, Ley I MJ).
- Tri-licencia abierta → `license: MIT` de skills HSCSG.

**EXTIRPAR (infra ajena — principio anfibio):**
- **GitHub como sede única** → reemplazar por almacenamiento HSCSG local (Zustand + Nostr federation). El repo es la "sede"; HSCSG la hace offline-first.
- **Meetup/eventos externos** → modelo de `events` en estado local (no dependencia de terceros).
