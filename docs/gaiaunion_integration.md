# Integración Gaia Union — Perspectiva Triple (Usuario · LLM · HSCSG)

**Fuente:** documento `.md` local "Gaia Union: El Plan Maestro Integrado para la Emergencia Planetaria". Ontología de ecosistema vivo (organismo regenerativo).

## 0. Síntesis
Gaia Union modela un nodo/planeta como **organismo vivo** con niveles (célula→tejido→órgano→sistema→organismo) y **sistemas vitales** análogos a los biológicos. Esto es la **capa ontológica/biológica** que el `/pipeline` mecánico de HSCSG aún no tenía: no solo un loop de datos, sino un *cuerpo* con órganos especializados y un "ADN" de valores.

## 1. Perspectiva del Usuario
Quiere ver su nodo no como una app, sino como un **organismo vivo** donde cada módulo es un órgano, cada persona una célula, y la gobernanza es "epigenética" (se adapta sin traicionar la esencia). El matchmaker y el feedback deben operar *dentro* de ese cuerpo.

### Extirpo
- Gaia Fund como *financiamiento externo* (donaciones/inversiones USD) → en HSCSG es ZNU/CaaS (postmonetario, sin EVM).
- BioHabitats físicos reales (ecovaldeas) → se modela como `/base` (base material local), no se construye infra física.
- Nombre "Gaia Union" → se integra como módulo `/gaiaunion` (corona la ontología del vaso, junto a Gaia Confederation).

## 3. Perspectiva HSCSG + CaaS (postmonetario)
- **Ley I**: BioHabitats/base material + Homeostático (DAO) protegen la vida; el loop no daña la base.
- **Ley II**: Fund Circulatorio = ZNU por AUT×CDS (acceso por contribución, no por dinero).
- **Ley III**: Hub Nervioso (FRS/Verificación) + Constitution (MJ) = transparencia radical, nunca engañar.

## 4. Interrelaciones / Correlaciones con el Pipeline Anidado (lo que pidió el usuario)
El `/pipeline` actual (CDS→OAD→COS→ITC→FRS) se **reencuadra como el sistema nervioso + circulatorio** del organismo Gaia Union:

```
ÓRGANO NERVIOSO (FRS/pipeline): observa → matchmaker (alook) decide → ejecuta
ÓRGANO CIRCULATORIO (ZNU/ITC): premia la contribución del loop
ÓRGANO HOMEOSTÁTICO (CDS/WisdomCouncil): equilibra bienes comunes
ÓRGANO METABÓLICO (Solarpunk/Tekitl): intercambio regenerativo
ÓRGANO DE APRENDIZAJE (Aprender): retos = mitosis celular (crece el tejido)
ÓRGANO EVOLUTIVO (Integral COS/Bounty): incuba nuevos órganos
ÓRGANO TERRITORIAL (Base): BioHabitat del nodo
```

**Matchmaker (alook)** empareja *células* (personas) con *órganos* (necesidades) según su peso (AUT+credibility+expertise+retos). **Feedback (FRS/automaton)** es el sistema nervioso que retroalimenta cada órgano. **Flujos de trabajo (ponytail)** son los "reflejos" del organismo (una línea resuelve).
