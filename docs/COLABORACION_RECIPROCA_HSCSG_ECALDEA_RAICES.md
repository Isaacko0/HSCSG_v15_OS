## 1. PREMISA FILOSÓFICA: DOS EXPRESIONES DE LA MISMA SOBERANÍA

### 1.1 El Isomorfismo Fundamental

> **Holosociocibersimbiogenesis (HSCSG)** y **Red de Intercambio Federada Ecoaldea Raíces del Monte** son **dos capas de la misma arquitectura de soberanía**:
>
> - **HSCSG** = Capa *meta-sistémica*: ontología, epistemología, protocolo de gobernanza, motor de valor, infraestructura digital soberana
> - **Ecoaldea Raíces** = Capa *territorial-encarnada*: tierra, agua, energía, alimento, comunidad, gobernanza viva, trueque físico

**No hay "integración" — hay *reconocimiento mutuo* de isomorfismo.**

| Dimensión | HSCSG v15 OS | Ecoaldea Raíces del Monte |
|-----------|--------------|---------------------------|
| **Unidad soberana** | Tribu fractal / Nodo HSCSG | Nodo federado autónomo / Ecoaldea |
| **Base material** | Cuaternidad Soberana Ampliada (13 pilares × 7) | Canasta básica 500 TQ = 1 TQ = 1 kWh |
| **Métrica de valor** | ZNU / NetBenefit / priceParity | TQ (crédito mutuo, saldo cero, ancla energética) |
| **Gobernanza** | 5 planos + Cuaternidad + Sorteo incentivado | 3 niveles (Federación/Aldea/Org) + Asamblea + Junta Directiva |
| **Federación** | Vasos Comunicantes (6 + 2 nuevos) | Piscina global multilateral + bilateral + sponsor/propagación |
| **Identidad** | DID soberana + RAO (ERC-8004) + MJ Gate | Ed25519 por nodo + hash chain + verificación 4 opciones |
| **Off-grid** | Modo desconectado + sync diferido | Nodo satélite (cache + cola eventos) |
| **Cultura** | Cultura anidada / Tribu fractal (8+ perfiles) | Perfiles nodo dinámicos (8 oficiales + custom) + gossip |
| **Módulos vivos** | Skills Hermes anfibios (WASM/QuickJS) | Drivers .nfcpkg auto-instalables (Goja sandbox) |
| **Ritual** | Encuentros tribales estacionales (4/año) | Feria Conuquera mensual + solsticios/equinoccios |

### 1.2 La Tesis Central

> **La Ecoaldea Raíces del Monte *es* una instancia encarnada de HSCSG.**  
> **HSCSG *es* el protocolo generalizable que la Ecoaldea Raíces valida en territorio.**

La colaboración no es "entre proyectos" — es **entre capa de protocolo y capa de encarnación**. Cada una necesita a la otra para completarse:
- HSCSG sin territorio = abstracción sin ancla física (riesgo: fantasma digital)
- Ecoaldea sin protocolo generalizable = isla que no federada (riesgo: fragmentación)
