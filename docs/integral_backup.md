Los 5 subsistemas (loop cerrado, cybernetic):
- CDS: problemas→propuestas→deliberación→decisión (sin votación mayoritaria)→dispatch a OAD/COS/ITC/FRS. Append-only, tamper-evident.
- OAD: diseños certificados (versionados, eco-assessed) → alimenta COS (labor-steps) e ITC (access values).
- ITC: time-credits por trabajo necesario; NO transferible, NO acumulable (decay), acceso proporcional. Metabolismo del sistema.
- COS: convierte diseños OAD en producción (tasks, labor, materiales, QA). Genera datos para ITC y FRS.
- FRS: observa COS/ITC/OAD/CDS → señales → diagnósticos → recomendaciones (advisory). Solo CDS hace decisión. Modela futuro (contrafactuales).

Principios estructurales no negociables:
- ITC jamás transferible entre participantes; democracia no genera créditos.
- FRS es advisory: solo CDS decide. Límite estructural anti-tecnocracia.
- Decision Records append-only, inmutables, solo superseded.

Isomorfismo con HSCSG (Materialismo Jerárquico):
- ITC ↔ ZNU (demurrage/decay = no estratificación) y CaaS (acceso por contribución).
- CDS ↔ Priorizar/Colectivo (deliberación) + Verificación (provenance).
- OAD ↔ Solarpunk (open commons) + Tekitl (blueprints de proyecto).
- COS ↔ Tekitl (roles/voluntarios) + Autómata Soberano (supervivencia por base material).
- FRS ↔ Lucidez + Verificación + Colaberry (nervous system del nodo).
